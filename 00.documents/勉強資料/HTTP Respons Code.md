## 【HTTPレスポンスコード】（JP）

| Code | 内容 | Remarks |
| :-- | :-- | :-- |
| 400 | 400（Bad Request）：ID／パスワード認証失敗など | クライアントがサーバーへ送信したリクエストの文法が誤っている、または必要なデータが欠落しているなど、**クライアント側の問題** によりサーバーがリクエストを理解または処理できない場合に発生 |
| 401 | 401（Unauthorized／認証失敗）：「誰であるかを証明してください」（ログイン／認証が必要） | クライアントが要求したリソースへアクセスするための**有効な認証情報（ログイン資格情報など）** が存在しない、または無効なためにリクエストが拒否されたことを意味する |
| 500 | 500（Internal Server Error） | サーバー内部で予期しないエラーが発生し、クライアントのリクエストを処理できない場合に返される一般的なエラーコード。**サーバーが具体的なエラー内容を公開できない場合** に使用されることが多い |

## [HTTP 응답 코드] (KR)

| Code | 내용 |　Remarks |
| :-- | :-- | :-- |
| 400 | 400 (Bad Request): ID/Password 인증실패등 | 클라이언트가 서버에 보낸 요청의 문법이 잘못되었거나, 필요한 데이터가 누락되는 등 클라이언트 측의 문제로 서버가 요청을 이해하거나 처리할 수 없을 때 발생 |
| 401 | 401 Unauthorized (인증 실패): "누구인지 증명해주세요" (로그인/인증 필요). | 클라이언트가 요청한 리소스에 접근하기 위한 유효한 인증 정보(로그인 자격 증명 등)가 없어서 요청이 거부되었음을 의미 |
| 500 | 500(HTTP 500 Internal Server Error) | 서버 내부에서 예상치 못한 오류가 발생하여 클라이언트의 요청을 처리할 수 없을 때 나타나는 일반적인 오류 코드 : 서버가 구체적인 에러내용을 알려줄수 없을때 |
